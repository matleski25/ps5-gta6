## Jak działa strona

Strona zbiórki z mini grą z Lucią. Licznik co godzinę pobiera stan zbiórki z buycoffee.to (GitHub Actions, plik `.github/workflows/pages.yml`) i na nowo publikuje stronę na GitHub Pages.

- Tekst, ceny i link do wpłat: blok `CONFIG` w `index.html`.
- Ręczne odświeżenie licznika: zakładka Actions → „Strona i licznik zbiórki” → Run workflow.
